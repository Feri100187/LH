# 湖面鸭群

## 素材与接入

- 使用网上下载的 **Mallard duck / Poly by Google**：[原素材页面](https://poly.pizza/m/frSLi6b6Vid)，[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)。原始 GLB、来源页面及完整许可证已保存。
- 单鸭 656 三角形、1 个网格、1 个材质、1 张 1024×1024 底色贴图，约 0.50 米长。仅做尺度、水线原点、纹理尺寸和名称整理。
- 五只实例共享原生 Duck 预制体，分为三只近岸和两只稍远；轻微尺寸差别在审计的鸭体包络内。
- 使用独立 `LakeDucks` 场景组，两个游戏场景均已接入。路线、周期和起始相位可在每个鸭子节点的 LakeDuck 组件中调整。

- `placement_audit.json`：当前原生湖面等 7 个网格与 GLB 一致；完整路线处于水域内；出生点的 45 条环境遮挡检查通过。
- `runtime_math_tests.json`：10/10 PASS；调用真实 LakeDuck 方法，检查周期、朝向、水位、浮动、1000 圈无累积漂移、实例数量及资源释放。
- TypeScript 检查、两场景和鸭群预制体 Schema 检查通过。新增脚本导入后，受影响的玩家输入/方向测试也分别 25/25、24/24 通过。
- LayaAir 实际从出生点及近岸观察，鸭体、绿色头部和白颈环正常，腹部接触水面，蹼足在水下。截图为 `ide_spawn_view.png`、`ide_shore_view.png`。
- Web 发布版实际读取 5 只鸭子的动态位置；间隔观测中位置发生变化，根 Y 保持约 0.04。第一、第三人称画面均已查看，控制台无警告或错误。
- Web 与 single-html 均已构建；单文件入口本轮未独立运行，手机真机未测试。
