# 第一人称与八方向移动

## 修改

1. 完整世界角色仅在第三人称显示；第一人称使用前臂、袖口、双手、水枪与水流的独立蒙皮模型，共 15 个网格。后续袖面连续性修复后为 41,369 三角形，详见 `docs/player_camera_arm/修复记录.md`。肩、胸腹、头、腿均不在视模中。俯仰由相机父节点统一带动，袖管末端位于画外。
2. 相机跟随从顶层 Scene 的 `onUpdate` 移到 Camera 上的 3D Script `onAfterSceneUpdate`。本机引擎先运行顶层脚本，再计算 3D 物理，原相机因此读到上一帧位置；现在相机使用本帧物理与骨骼更新后的结果。
3. 身体 Yaw 只由视线决定；W/S/A/D 和组合键选择八方向 Walk/Run 动作，S 不再让人物转身。新增十四个真实 IK 动作，原六个动作逐采样保留，根骨不随移动方向旋转。
4. 方向切换通过原生状态机转换，保留循环步相，并加方向边界滞回以避免摇杆抖动。侧移、后退按各自动作的实测步程限速，播放倍率继续依据实际位移。
5. 连续射击、鼠标锁定保护、跳跃与触屏输入保留；第一/第三人称切换时射击动作同步到当前周期。
