# 凌水湖游戏场景修复记录

本次修复写入 `D:/a/xiang_mu/LH`，启动场景仍为 `assets/Scene.ls`。原模型和修改前的项目资源均保留备份。

## 已修复的问题

- **道路穿楼、铺装悬空与草坡尖角**：临湖楼前红道绕开楼体和门柱，与连续硬质前场及两端缓坡衔接；同步移动受影响的植物实例和树干碰撞。
- **白色折返楼梯镂空、扶手挡路**：修正反向面，重做有厚度的踏步和转角平台；打通桥端、楼梯底部与曲线栈道的扶手接入口，并切除桥口额外的实体护沿门槛。
- **草地穿出台阶**：依据实际踏面边界局部细分和压低地形，清除折返梯、西岸宽台阶、看台和桥面下露出的草地。60,141 个采样无穿插，最小净空约 18 cm。
- **亭旁草洲缺失**：纠正封闭网格方向，草地顶面完整恢复，面积约 43.52 平方米，标高比水面高约 46 cm。亭台侧梁、檐梁、坐凳和栏杆的反向面同时修正。
- **湖面网格与平板感**：关闭覆盖湖面的编辑器辅助网格；新增不依赖顶点切线的动态波纹、水面视角反射和场景环境倒影，水边保留部分透视。反射探针位于开阔水域，避免被修复后的草洲封在内部。
- **楼梯卡脚与门廊接缝**：视觉保留实体台阶，三处阶梯的游戏碰撞采用连续行走坡面和水平平台，保留原护栏碰撞；入口台基使用局部碰撞过渡，人物参数不变。

## 验证方式

从鸟瞰、折返梯、楼前红道、草洲、低视角湖面、西岸台阶、亭子栈道和桥口共 8 个方向检查实际 Web 游戏画面，也在 LayaAir 内置预览确认场景正常加载。

源模型、GLB 和 14 个修复后的原生网格逐项核对；场景和预制体通过 LayaAir Schema 校验，资源引用未发现缺失。楼梯的渲染模型与平滑碰撞有意不同，分别验证。

通行测试仅在每条路线起点设置人物位置，之后使用浏览器真实触屏事件驱动摇杆和游戏物理，不在中途传送或跳跃。覆盖折返梯上下桥、西岸阶梯往返、亲水弧梯往返、临湖红道、亭子支路往返和门廊入口。结果与具体坐标见 `运行验收.json`。

预览图 `after_01` 至 `after_08` 是游戏内相机截图；为便于检查，截图时暂时隐藏 HUD 和玩家模型。游戏场景保留正常人物与操作界面。`before_*.png` 保留同机位修改前画面。
