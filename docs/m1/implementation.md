# M1 水枪命中与三个训练靶

输入基线：`d44e0967938d2c4bb5b0d05d31593219b62e9cbb`。开始时远端 `main` 与本地一致，工作区干净。保留 M0.1 的移动、单调射击时钟、连射期限、释放/失焦/长帧清理，不重新实现控制器。

## 玩家体验

出生点后方的草坪有三个编号圆靶：近靶约 4.8 米、中靶约 14.8 米、掩体靶约 7.5 米。独立遮挡板挡住从出生点直射第三靶的路线，需要绕到侧面。草坪位置来自当前碰撞几何采样，不占红路和灰路。

沿用鼠标左键、F 和触屏按钮；第一人称与越肩共用同一发射链。水枪有效射程为 18 米。命中靶面后，靶环变绿、编号换成勾，准星出现短暂命中标记，靶面有水花。左上角显示完成进度，3/3 时提示完成。点击“重新开始”或按 R 重置；重置会释放旧输入，下一次输入可重新游玩。

没有增加敌人、伤害、弹药/有限水量、计时挑战或联机。

## 职责分离

| 文件 | 职责 |
|---|---|
| `PlayerAvatar.ts` | 在原 `emitShot()` 内派发唯一 `{id,atMs}`；单个监听入口，替换监听不重播历史；原射速逻辑不变 |
| `WaterGunSystem.ts` | 接收发射、同帧物理后结算、连接进度/表现、重置和有界诊断 |
| `WeaponMuzzle.ts` | 读取已验证的 TPS/FPS `water_jet` 骨骼世界原点，禁用旧演示水流节点 |
| `PhysicsWaterQuery.ts` | 调用真实 Bullet 射线、复制结果、筛掉自体、选择最近命中，墙面同距离优先 |
| `WaterShotResolver.ts` | 不依赖引擎的射线几何和射程规则，无计时器 |
| `TrainingProgress.ts` | 严格递增发射 ID、水位保留、每靶一次完成 |
| `TrainingRangeView.ts` | 三靶、支架和遮挡板的程序几何及完成外观 |
| `WaterShotEffects.ts` | 固定 4 组水束/水花池，仅呈现结算结果，不发射或检测目标 |
| `TrainingHud.ts` | 进度、提示、重置按钮和 R 入口 |

`LingshuiGame.ts` 仅增加初始化、物理后调用、输入清理联动、状态和销毁入口。没有把检测、靶状态或 UI 细节继续塞进控制器。

## 一发的顺序

1. 原 Avatar 单调时钟到期，`emitShot()` 增加既有计数并派发一次事件。系统记录 ID、实际时间和游戏更新帧号。
2. 同一帧 Bullet 和 Animator 更新完成、原相机跟随完成后，取最终相机光轴、对应视角的枪口骨骼位置和身体内侧锚点。
3. 相机中心射线找准星瞄准点；查询距离覆盖枪口射程和第三人称相机偏移。
4. 从身体内侧锚点检查到枪口的短路径，防止枪管已经伸进或穿过墙体。被阻挡就停止于该位置，不从墙后枪口继续画水流。
5. 枪口朝瞄准点方向查询完整 18 米有效射程，只取最近的世界或靶面碰撞。准星表面点决定方向，不作为第二射线的提前截断距离。
6. 发射 ID 消费一次，最多一个靶子响应。水束终点和水花位置直接来自该次检测；帧更新只衰减表现，不重复结算。

过期、跨帧或时间倒退的队列不在新姿态下补结算。重置保留已发射 ID 水位，清除待结算和旧输入；历史 ID 不会因重置、监听替换或切视角重新生效。诊断最多保留最近 64 发结算，累计计数和防重水位不受此裁剪影响。

### 查询分组与精度

原世界静态物体为 group 1 / mask 2，玩家为 group 2 / mask 1。训练靶面用 group 4 / mask 2，支架/遮挡板仍是 group 1 / mask 2。查询明确用 **group 2 / mask 5**，同时包含墙与靶、排除玩家。另按 collider 的 owner 祖先排除玩家。

安装版 `rayCastAll` 返回未排序、池化的后端 collider 数据，适配器立即复制点/法线/身份并按世界距离选择。它会微扩实际查询末端 2 mm 以包含 Bullet 的精确端点，但拒绝超出请求段超过 0.01 mm 的结果；浮点边界夹回请求距离，不增加有效射程。

当前相机是对称透视、全视口，光轴对应屏幕准星中心。没有调用安装版实现存在坐标疑点的 `normalizedViewportPointToRay(.5,.5)`。实际 GUI 拖动和命中记录验证了中心一致性。枪口由最终 GLB 反绑数据核实，不能使用早期模型的额外 .066 米偏移。[安装源码与资产证据](engine-and-muzzle-notes.md)。

### 本轮真实失败及修正

首轮精确瞄准靶心时，准星射线已命中圆靶，但枪口射线被截到该表面点。Bullet 的凸体查询从不同方向逼近表面，交点可略在这个长度之后，造成脱靶。原始失败见 `runs/20260921/final-functional-60-fp.json`。

修复让准星点仅决定方向，枪口仍查询完整配置射程，任何中间墙体仍会先阻挡；没有放宽射程或适配器容差。新增负对照先在旧实现下失败，再验证同一圆靶表面多出 3 mm 的真实可达交点、墙体阻挡、超射程拒绝及脱靶完整长度。

## 资源与构建

训练组和效果都是独立运行时节点，靶子编号也由少量几何组成，没有新增外部贴图或更换人物模型。程序资源在 `config/assets.manifest.json` 的 `runtimeGenerated.m1TrainingRange` 登记。仅新增脚本自己的 `.meta`；既有 UUID、模型、动画、场景、水面和鸭群资源不改。588 个原锁定资源仍逐字节核对。

所有自建几何、材质、HUD、监听和效果池由所属对象销毁。旧 `FX_WaterPulse` 只在运行时禁用，原资源和动画不被改写。

第二次增量 CLI 构建停在 `validate scene`，终止的都是该次专用 CLI 进程，失败报告保留。随后在独立工作目录恢复 LFS 并冷构建成功，没有清空原项目编辑器缓存，也没有升级 3.4.1 或改物理引擎。
