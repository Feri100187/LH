# M1 水枪训练原型（草稿，未完成原生验收）

基于 `d44e0967938d2c4bb5b0d05d31593219b62e9cbb`。本轮交付命中规则、LayaAir 适配组件和独立训练场景，不修改 M0.1 的运行控制器、射击时钟、原始场景、资源 UUID 或启动设置。不能把本原型或这里的模拟测试称为已经通过引擎/真机验收的 M1 成品。

## 内容与入口

用 LayaAir **3.4.1** 打开工程后，打开并运行 `assets/M1Training.ls`。它复用原 `Scene.ls` 的全部子节点、资源引用和参数，只改变根名称/id 并追加 `WatergunTraining` 组件。默认启动场景仍是 `assets/Scene.ls`；直接运行旧的 `启动游戏.cmd` 不会自动得到训练玩法，也没有在本轮重建 `release/web`。

训练包含三枚悬浮球形靶、第三靶前的遮挡板、每靶三次命中进度、完成提示、准星反馈和重置按钮。桌面先按 Esc 再点击重置；触屏可使用按钮。训练物体在运行时生成，不需要新模型或纹理。坐标是基于出生点的初始布局，尚未在真实画面中验证地形遮挡与可绕行角度，不能称为最终关卡。

`WatergunHit.ts` 是不依赖引擎的规则层；`WatergunTraining.ts` 负责物理射线、场景对象和 HUD。组件在原 `PlayerCameraFollow.follow` 完成之后执行，并在销毁时仅恢复自己拥有的回调；没有修改原相机跟随方法。

## 命中与计时边界

仅消费 M0.1 `PlayerAvatar.getStatus().shotEvents` 的最新实际发射记录，按递增 id 去重，丢弃过期、失焦和隐藏时的记录；不从按键状态、动画循环或独立定时器推导新发射，也不回放历史环形缓冲。原约 0.2 秒射击周期和低帧保护保持原样。

准星射线确定瞄准点，然后从世界角色已有 `water_jet` 枪口骨骼朝瞄准点检测最近表面，射程以世界枪口为起点限制为 20 米。胸部到枪口的短射线防止枪口伸过薄墙后从墙外开火。查询组沿用 2，世界遮挡掩码为 1，训练靶为 4；玩家移动掩码不改。鸭子不是训练目标。

第一人称视模枪口只决定水线的视觉起点，不能决定命中。训练场景暂时隐藏原先不带遮挡判断的短水流网格，用解析出的水线/落点替代；销毁时恢复当前视角对应的显示。水线和落点是占位视觉，不是真实流体。真实骨骼更新次序、低头/跑跳时的对齐、近墙截断仍须原生画面验收。

规则重置只清目标进度，不重置玩家发射 id/射击时钟，不能让同一发重复生效。特效为一个可复用水线和一个落点网格，不逐发累积物体。当前只读状态接口在射击期间会复制最多 256 条记录，原生性能验收需检查这部分成本；不要在未测量前宣称没有额外开销。
