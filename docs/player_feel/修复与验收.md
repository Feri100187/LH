# 动作与射击手感修复

## 原因与修改

- 原行走的支撑脚只移动约 0.50 米，却搭配 4.5 米/秒的移动速度；跑步也存在步程与速度不符。新动作扩大步幅，并按支撑阶段的真实脚踝位移计算播放频率：Walk 参考速度 1.63636 米/秒，Run 3.94737 米/秒。游戏目标速度改为 1.65 / 4.0 米/秒，摇杆小幅移动也同比减慢步频。
- 重新制作 Idle、Walk、Run、Shoot，并调整跳跃的持枪姿态。行走有髋胸反向扭转、重心移动、头部稳定与枪体微摆；待机/行走枪口朝前，跑步侧持。逐帧使用同一武器控制器驱动双手 IK，保持包握接触。
- 原 Shoot 长达 2.5 秒，含抬枪、三次发射与收枪，并禁止未播完时再次触发。现为首帧出水的 0.2 秒循环；左键/F/触屏按钮按住连续发射，松开后当前脉冲结束即停，快速点射可排队。
- 报错来自当前 LayaAir 的 InputManager：canvas 的 pointerdown / pointerup 回调无条件捕获或释放指针，与 Pointer Lock 冲突。现于捕获阶段把锁定中的事件交给游戏输入层，其他正常指针输入保留引擎路径。未修改引擎安装文件。
- 引擎物理使用固定步，渲染帧可能不更新物理位置。原单帧位移会偶尔读到零并切回 Idle；速度改为短时间滑窗统计实际位移，松开、失焦、重生清空。动作仍由实际移动驱动。
