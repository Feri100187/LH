## 边界问题修复

- 失地超过防抖阈值的当帧立即标记已腾空，避免下一帧已接地时卡在跳跃；低顶阻挡导致未离地的跳跃请求也会超时复位。
- 使用正弦/余弦归一化角度差，并归一化累计朝向，连续转动多圈仍沿最短方向转向。
- `tools/test-player-avatar.cjs` 编译并调用真实 `PlayerAvatar.step()`，用轻量引擎替身隔离逻辑；结果见 `edge_case_tests.json`。这项测试补充原生运行检查，不替代物理与画面验收。

## 范围与限制

- 射击目前是人物动作及模型内水流表现，没有新增命中判定、伤害或敌人系统。
- 触屏验收使用桌面浏览器的触屏界面和窄屏视口；手机真机多指硬件、性能与不同 GPU 尚未测试。
- 本地 Web 版本用于正常键鼠试玩。Codex 内置浏览器不支持此游戏的鼠标锁定，内置预览可用 `?controls=touch` 操作。
- 第一人称隐藏头颈以避免相机穿入脸部；原始模型数据未删减。
