# 镜头位置与颈部比例

## 镜头

右肩后拉距离由 2.35 米缩短到 1.95 米；相对跟随锚点的高度偏移由 0.14 米增加到 0.32 米。右侧偏移为 0.65 米。两场景均显式保存新参数，代码默认值同步更新。第一人称镜头参数不变。

## 颈部

颈部中段横向加宽约 16%，颈根约 18%，前后厚度增加约 10–11%，到颌下逐渐回到原尺寸。高度、骨骼权重与拓扑不变，最大顶点移动约 7.7 毫米。模型调整前的实际越肩画面为 `camera_neck_before.png`。

独立源工程为 `source_art/AnimeWatergunBoy/neck_refine_20260920/AnimeWatergunBoy_NeckRefined.blend` 与同名 GLB。新旧 GLB 比对确认只修改 mesh 26 `AWB.Neck.mesh.001` 的位置和法线；其余 43 网格、材质、骨架及 20 个原始动作一致。游戏中仅更新该 `.lm`，既有动作与预制体引用继续有效。

已查看正面、侧面、背面、四分之三近景前后对比，并抽查待机、行走、奔跑、跳跃和射击的颈部/衣领衔接。几何记录与比对报告位于源工程目录的 `qa/`。

以后重新生成角色游戏副本时，使用：

```text
python tools/prepare-player-assets.py --model-source source_art/AnimeWatergunBoy/neck_refine_20260920/AnimeWatergunBoy_NeckRefined.glb
```

该源包含当前 20 个动作，脚本会处理根位移并补出 4 个腾空/落地片段。
