# 游戏动作修订

原始 `rigged_20260919` 资产保持不变。本目录包含新动作的可编辑 Blender 工程与导出 GLB。

## 动作

| 动作 | 时长 | 用途 |
|---|---:|---|
| Idle | 3.0 秒 | 面朝前方的双手持枪警戒待机，轻微呼吸与重心变化 |
| Walk | 22/30 秒 | 前向持枪，髋胸反向扭转、移重、完整脚部支撑与摆动 |
| Run | 18/30 秒 | 侧向收枪奔跑，更大步幅、上身前倾与起伏 |
| Jump | 1.4 秒 | 保留原跳跃时序，双手改前向持枪 |
| RunJump | 1.6 秒 | 保留原跑跳时序与根运动，双手改前向持枪 |
| Shoot | 0.2 秒 | 首帧出水，持续循环；轻微扳机与枪体运动，无抬枪收枪前摇 |

Walk 支撑相占周期的 60%，脚踝相对根骨移动 0.72 米，匹配速度 **1.636363636 米/秒**。
Run 支撑相占周期的 38%，脚踝相对根骨移动 0.90 米，匹配速度 **3.947368421 米/秒**。
运行速度变化时，应将动作播放倍率设置为“实际水平速度 / 上述参考速度”。

## 检查

- `qa/gameplay_motion_quality.json` 和各动作 `*_all_frames.json`：逐帧手腕/踝 IK、鞋底最低点、枪口朝向、首尾环路误差。
- `qa/bind_compatibility.json`：与原 GLB 的静态节点 TRS 和 inverse bind 矩阵逐项比较，最大差均为 0。
- `previews/`：实际 Blender 渲染，已检查待机正侧面，以及行走/跑步关键姿势。
- 首尾一致的动作：Idle / Walk / Run / Shoot。Jump / RunJump 为一次性动作。
- 模型几何、材质、骨架名称、控制器结构没有变更；右手后握把、左手前握持的原绑定关系保持。

Blender 前方为 -Y，GLB 前方为 +Z。游戏导入时，沿用项目的根位移移除流程，以物理控制器驱动移动与跳跃。

复现脚本：`tools/author-gameplay-motion.py`。它从原 .blend 读取，输出始终写到本目录。
