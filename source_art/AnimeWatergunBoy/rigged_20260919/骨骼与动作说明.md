# 双手持水枪男生：骨骼与基础动作

## 文件

- `AnimeWatergunBoy_Rigged.blend`：可编辑骨架、权重、IK 控制器和六个独立 Action。
- `AnimeWatergunBoy_Rigged.glb`：同一角色的骨骼蒙皮和六个动画片段，已实际重新导入 Blender 核对。
- `previews/00_AllActions.mp4`：全部动作的视频预览。
- `previews/01_Idle.mp4` 至 `06_RunJump.mp4`：单独动作预览。部分短动作重复播放便于观察，不改变 GLB 内原始片段时长。
- `previews/GLB_*.png`：导出模型重新导入后的关键姿态渲染。

## 动作清单

统一以 30 FPS 制作。Blender 帧从 1 开始，GLB 动画时间从 0 秒开始。

| Action | 内容 | Blender 帧范围 | 时长 | 循环 / 位移 |
| --- | --- | --- | --- | --- |
| Idle | 持枪待机、轻微呼吸和重心变化 | 1–91 | 3.000 秒 | 首尾循环 |
| Walk | 双手持枪行走、脚跟落地及蹬离 | 1–33 | 1.067 秒 | 原地循环 |
| Run | 持枪跑步、交替摆腿及腾空阶段 | 1–23 | 0.733 秒 | 原地循环 |
| Jump | 下蹲蓄力、起跳、腾空、落地缓冲 | 1–43 | 1.400 秒 | 单次；含垂直位移 |
| Shoot | 抬枪瞄准、扣扳机、三次水流脉冲、收枪 | 1–76 | 2.500 秒 | 单次，返回待机姿势 |
| RunJump | 前进起跳、跨步腾空、落地停稳 | 1–49 | 1.600 秒 | 沿 Blender -Y 前进 1.85 米 |

Walk 和 Run 供游戏控制器移动角色时使用；其支撑脚相对原地角色向后移动属于正常原地步态。可参考移动速度约 0.73 米/秒与 2.2 米/秒，再结合引擎中的动画速度调节。RunJump 已包含根骨骼的前进位移，不应再重复叠加同样的角色位移。

## 骨架与控制

- Blender 内共 **64 根骨骼**，包含 **55 根变形骨骼**及 **9 根 IK / 极向控制骨骼**。
- 导出 GLB 保留 55 个骨骼关节；控制约束的结果已按帧采样。
- 44 个网格全部蒙皮，包含独立水枪和可选水流效果。约 125,460 三角面。
- 每个顶点最多 4 根影响骨，权重已归一化。
- 绑定姿势保持原角色的双手持枪姿势。

主要控制器：

- `root`：整体位移。
- `pelvis / spine / chest / neck / head`：身体和头部姿态。
- `CTRL_foot.L / R`：脚部双骨 IK；`POLE_knee.L / R` 控制膝盖弯曲方向。
- `CTRL_weapon`：移动或旋转水枪时，两只手通过各自握持目标共同跟随。
- `CTRL_hand.L / R`：调整左右握持位置。
- `POLE_elbow.L / R`：肘部弯曲方向。
- `thumb / index / middle / ring / little`：每根手指有 3 节 FK 骨骼。
- `trigger`：扳机；`water_jet`：简化水流脉冲。

工程默认选择 `AWB_Rig` 并启用 Idle。可在动作编辑器的 Action 下拉框切换六个动作，播放范围使用表中对应的帧范围。NLA 中保留六条独立、默认静音的动作轨道，避免与当前 Action 重叠播放。

## 使用范围

这套内容是可编辑的基础角色动作，没有添加游戏输入、伤害判定、碰撞控制或动画状态机。水流为轻量网格效果，不是流体仿真；可以单独替换为引擎粒子效果。

当前动作针对已有持枪造型制作。大幅改变握持方式、体型或服装后，仍应重新检查权重与接触。原始静态工程与凌水湖场景未被覆盖。
