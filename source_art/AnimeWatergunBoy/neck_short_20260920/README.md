# 颈部缩短版

基于 `neck_refine_20260920` 的加粗版，完整头部、五官、耳朵、头发和眼镜一起下移 **2.4 厘米**。颈根保持固定，颈部上半段平滑压短，最上端与头部采用相同位移。保留上一版横向和前后加厚效果。

没有缩放头部，没有挪动衣领、衣服、手枪或镜头，也没有改变骨骼、绑定权重和动作。

## 游戏导入范围

**必须更新全部 14 个网格，不能只更新 neck。**

GLB mesh index：`6, 7, 8, 9, 10, 11, 12, 13, 15, 16, 17, 18, 21, 26`。

其中前 13 个为头部/面部/头发/眼镜，26 为 `AWB.Neck.mesh.001`。名称和索引保持原样；仅这些网格的位置与重新计算的法线改变。

- 其余 30 个网格的 accessor 数据逐字节一致。
- 默认节点和 TRS 一致。
- 蒙皮关节顺序与 inverse bind 矩阵字节一致。
- 材质一致。
- 全部 20 个动作的输入时间和输出采样逐字节一致。

因此原有骨架、动画、材质、状态机及场景变换可以继续使用。

## 验证

逐帧检查全部 20 个动作，共 564 帧：颈顶一圈 40 个点始终处于头部内部，最小重叠余量约 **9.6 毫米**；颈根 200 个顶点保持原位置。实际渲染并查看了正、侧、背和四分之三视角的前后对比，以及待机、行走、奔跑、跳跃和射击姿势，未见头部悬空或新增领口接缝。

- `previews/`：前后四视角与多动作近景。
- `qa/glb_shortened_head_preservation.json`：完整导出兼容性对比。
- `qa/all_actions_head_neck_attachment.json`：全部动作逐帧头颈重叠验证。
- `qa/neck_shortening_geometry.json`：具体网格位移。
